# auth-gate v0.5.1

Released 2026-11-25.

### Fixed

- Builds against crypt-io 1.6 and later. crypt-io 1.6 started refusing
  Argon2id parameters below the OWASP minimums in `argon2_hash_with_params`,
  so `PasswordPolicy::insecure_for_tests()` failed every hash (the gate would
  not build) and custom parameters above crypt-io's new default caps could
  not hash or verify.
- The unknown-account check now uses the same cost ceiling as a real check,
  so it does the same work for strong parameters too.

### Changed

- Building the gate with parameters below the OWASP minimums for Argon2id
  (for example 19 MiB with 2 passes) now fails at build with
  `AuthError::InvalidInput`, instead of failing each hash with
  `AuthError::Crypto`. `insecure_for_tests()` is exempt.
- Requires crypt-io 1.6 or later.
