# Security Policy

## Supported Versions

auth-gate is pre-release (`0.x`). Security fixes ship on the latest minor
line only.

| Version | Supported |
|---------|-----------|
| `0.3.x` | yes (current) |
| `< 0.3` | no |

## Reporting a Vulnerability

auth-gate decides who a request is and runs sign-in. A bug in it can be a vulnerability in every service that uses it.

Please report privately: email **me@jamesgober.com** with a description,
the affected version, and a reproduction if you have one. Do not open a
public issue for a vulnerability. You will get an answer within three
working days; a fix is released as a patch version, and the advisory is
published once users have had a chance to upgrade.
